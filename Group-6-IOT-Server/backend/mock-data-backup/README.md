# 🗄️ Mock Data Documentation (ฐานข้อมูลจำลอง)
## โฟลเดอร์ `backend/mock-data/` มีไว้ทำไม และเก็บอะไรบ้าง?

### 1. วัตถุประสงค์
โฟลเดอร์นี้สร้างขึ้นเพื่อ **จำลองฐานข้อมูลผู้ใช้ของ RADIUS / MySQL (กลุ่ม 1 และกลุ่ม 2)** ชั่วคราวสำหรับการพัฒนาและทดสอบภายในกลุ่มที่ 6 เอง เพื่อให้สามารถทดสอบ Flow การทำงานของหน้าเว็บ, Auto Check-In, และการตัดสลับห้องได้ทันทีโดยไม่ต้องรอให้กลุ่ม 1 และ 2 ติดตั้งเซิร์ฟเวอร์เสร็จ

---

### 2. ข้อมูลที่จัดเก็บภายใน (Single Demo User)
เก็บข้อมูลนักศึกษาจำลอง **เพียง 1 คนเท่านั้น** ตามข้อกำหนด:

* **ไฟล์:** `users.json`
* **รหัสนักศึกษา (Username):** `67200412`
* **รหัสผ่าน (Password):** `rujinat_fah`
* **ชื่อ-นามสกุล:** `Rujinat Fah`
* **สถานะ:** `ACTIVE`

---

### 3. Flow การทำงาน
```text
ผู้ใช้กรอกรหัส นศ. 67200412 + รหัสผ่าน rujinat_fah
       │
       ▼
backend/services/authService.js
       │ (อ่านข้อมูลจาก backend/mock-data/users.json)
       ▼
ตรวจสอบตรงกัน ➔ ส่งผลสำเร็จ (Valid) พร้อมชื่อ Rujinat Fah กลับไปให้ระบบทำงานต่อ
```

---

### 4. เมื่อถึงเวลาส่งมอบงาน (Production Handover)
เมื่อจะนำระบบขึ้นรันจริงบน Proxmox VM 106 และเชื่อมต่อกับ RADIUS (กลุ่ม 1) หรือ Auth API (กลุ่ม 3):
* สามารถลบโฟลเดอร์ `backend/mock-data/` นี้ทิ้งได้ทันที
* สลับการทำงานไปใช้การเรียก API หรือ RADIUS จริง ตามคู่มือ [`readme_to_connect.md`](../readme_to_connect.md)
