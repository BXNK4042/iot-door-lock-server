# 📚 Docs Documentation (สถาปัตยกรรมและการเชื่อมต่อภายนอก)
## โฟลเดอร์ `docs/` มีไว้ทำไม และเชื่อมต่อกับระบบอื่นอย่างไร?

### 1. วัตถุประสงค์
โฟลเดอร์นี้รวบรวมข้อมูลทางเทคนิคและการตั้งค่าเครือข่ายสำหรับนำโปรเจกต์ `Group-6-IOT-Server` ขึ้นรันบน **Proxmox VE (VM 106)** และเชื่อมต่อกับกลุ่มเพื่อนอีก 4 กลุ่มบนสายแลนเสมือน `vmbr1`

---

### 2. ข้อมูลการตั้งค่าเครือข่ายของกลุ่ม 6 บน Proxmox
* **VM ID:** 106
* **OS ใน VM:** Debian / Ubuntu Server
* **Internal IP (vmbr1):** `10.10.10.16` (ได้รับผ่าน DHCP จาก dnsmasq ของ Proxmox)
* **พอร์ตบริการของกลุ่มเรา:**
  * `3000`: Web QR Access & REST API
  * `1883`: MQTT (กรณีรัน Mosquitto ใน VM 6)
  * `22`: SSH สำหรับให้สมาชิกกลุ่ม 6 เข้ามาแก้ไขงาน (Forward ผ่านพอร์ต 2206 ของโฮสต์)

---

### 3. จุดเชื่อมต่อไปยังกลุ่มอื่นบนวง `vmbr1` (Zero Latency)

| ปลายทาง | IP และพอร์ต | โพรโทคอล | หน้าที่ |
|---|---|---|---|
| **กลุ่ม 3 (Auth API)** | `http://10.10.10.13:4000/api/auth/login` | HTTP REST (JSON) | กลุ่ม 6 ยิงไปตรวจสอบรหัสนักศึกษาและรหัสผ่าน |
| **กลุ่ม 4 (Web App)** | `http://10.10.10.16:3000/api/logs` | HTTP GET (Text) | กลุ่ม 4 ยิงมาดึงไฟล์ `log.txt` จากกลุ่มเราไปทำกราฟสถิติ |
| **กลุ่ม 1 (RADIUS)** | `10.10.10.11:1812` | RADIUS UDP | กลุ่ม 3 ใช้ตรวจสอบสิทธิ์กับกลุ่ม 1 |
| **กลุ่ม 2 (MySQL)** | `10.10.10.12:3306` | MySQL TCP | ฐานข้อมูลกลางที่กลุ่ม 1 และกลุ่ม 3 ใช้อ้างอิง |

### 4. การเปิดให้คนภายนอกเข้าใช้งาน (3 Ingress Scenarios)

#### 🌐 แบบที่ 1: ขอ Public IP จริง
* ตั้งค่า IPTABLES บน Proxmox โฮสต์: Forward พอร์ตภายนอก เช่น `80` เข้า `10.10.10.16:3000`
* นำ Public IP ไปสร้าง QR Code: `http://[PUBLIC_IP]/?room=LAB-401`

#### ☁️ แบบที่ 2: Cloudflare Tunnel (แนะนำที่สุด!)
* รัน `cloudflared` บน Proxmox โฮสต์ หรือใน VM 106
* แมปโดเมน: `door.myproject.com` ➔ `http://10.10.10.16:3000`
* ได้ HTTPS ปลอดภัยฟรีอัตโนมัติ

#### 🎮 แบบที่ 3: Playit.gg
* รันคำสั่ง `playit` บน Proxmox หรือใน VM 106
* ได้ URL สำเร็จรูป เช่น `http://iot-door.at.ply.gg:38421/?room=LAB-401`

### 5. ย้ำเตือนสำคัญ (Safety Notice)
* รันโค้ดทั้งหมดด้วย Node.js ธรรมดา (`node backend/server.js`)
* **ไม่มีการใช้ Docker โดยเด็ดขาด** เพื่อความปลอดภัยของระบบ Windows และ Proxmox
